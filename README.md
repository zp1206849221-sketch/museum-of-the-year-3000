# Museum of the Year 3000

A one-line entry for the make.fun "Museum of the Year 3000" contest: the
museum label a curator in the year 3000 places beside a fidget spinner,
confidently misreading the anxious toy of 2017 as a handheld prayer wheel
for manufacturing calm.

## How to run

```sh
python3 main.py
```

This creates `/output` if needed and writes the single label line to
`/output/entry.txt` (UTF-8, well under the 200-character gate).
